# Label numbers: four typed digits plus an era letter

A **label number** is four digits (0000–9999). Once those run out, a letter prefix is added (A0000…, skipping I and O), and numbers are never reused. People only ever type the four digits on a numeric pad; if several in-stock units share them, they pick one. The QR code carries the full number, so scanning is never ambiguous.

We rejected ever-growing numbers (longer to type over time), recycled numbers (old labels and history rows become ambiguous), and alphanumeric codes (phone keyboards with wet hands are slow and error-prone). Printed labels make this hard to change later.
