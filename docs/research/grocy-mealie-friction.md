# Grocy & Mealie: click-cost friction and common integration targets

Research for ticket #6 (map: #1). Researched 2026-11-11. This doc summarises; it does not decide.

**Source quality key:** **[P]** primary source (official docs, the project's own issue tracker, library source code). **[S]** secondary or only seen as a search snippet. Reddit and some forum pages could not be fetched directly from this environment, so their claims are marked [S] and should be spot-checked before anyone quotes them.

### 1.3 Recurring themes, condensed

1. **Setup tax:** product/food master data, units and conversions before the first useful action (G1, G2, M3).
2. **Per-action dialog cost:** due dates, amounts and price prompts on every buy or consume; no one-tap paths (G3, G4, G5).
3. **Labels are DIY:** Grocy delegates layout and printing to a webhook you write yourself; there is no pre-print and no batch (G6).
4. **Freezer as an afterthought:** Grocy's freezer logic is inconsistent; Mealie has none (G7, M1).
5. **Household acceptance:** partners won't use complex UIs; lists live in Bring!, Keep or Alexa instead (G8, M5).
6. **Macros:** Mealie's are manual and per recipe; users want automation but no tracker integration exists (M2).

**Observations (not decisions):**
- **Shopping lists:** no major consumer list app (Bring!, Keep, AnyList, OurGroceries) has an official read/write API for third parties. Home Assistant's `todo` abstraction is the one stable, official surface that already wraps most of them; Todoist, Google Tasks and MS To Do have proper official APIs. The only official Bring! inbound path (deeplink) requires the recipe page to be internet-reachable, which is why the community built a local push connector.
- **Macro trackers:** none of the big four (Cronometer, MFP, Yazio, FDDB) offers an open write API. The only sanctioned "push" path is a **public recipe URL with schema.org markup** that Cronometer (paid tier) and MFP (English only) can import. Even those re-match ingredients against their own database rather than taking the page's macros as-is. Unofficial write paths exist for MFP (cookies) and Yazio (embedded app credentials); both are brittle and ToS-sensitive.
